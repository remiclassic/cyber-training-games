# Cyber training games

Public site for Rémi Couture's gamified cyber training work: eight playable training games with gameplay video, quoted content, and how each is scored and tested.

Live: https://remiclassic.github.io/cyber-training-games/

- `index.html` — the page (static, no build step)
- `media/` — gameplay clips, posters, reel and timelapse
- `shots/` — debrief screenshots
- `play/` — playable builds of the eight games (static bundles)

All scenario content is fictional sample content.
